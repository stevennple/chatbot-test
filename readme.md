# StrikeMMA Test Chatbot
An AI-powered MMA coaching chatbot built with OpenAI's GPT-3.5 Turbo and Gradio. The chatbot specializes in answering questions related to Mixed Martial Arts training, techniques, and strategies.

## Quick Start
1. Clone the repository
```bash
git clone https://github.com/stevennple/StrikeMMA-ai.git
cd StrikeMMA-ai
```

2. Install dependencies
```bash
pip install openai gradio
```
3. Set up environment variable
```bash
export OPENAI_API_KEY=your_api_key_here
```

4. Run the application
```bash
python app.py
```

## Features
- MMA-specific AI coaching
- User-friendly Gradio interface
- Real-time responses using GPT-3.5 Turbo
- Error handling for API requests
- Shareable interface link

## Requirements
- Python 3.6+
- OpenAI API key
- openai package
- gradio package
